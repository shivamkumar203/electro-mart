# Electro-Mart

Electro-Mart is a lightweight e-commerce storefront built with Node.js, Express, and vanilla JavaScript.

## About

This project includes a shopping interface with product display, cart functionality, order pages, and a simple admin page.

## Repository

- GitHub: https://github.com/shivamkumar203/electro-mart
- Live demo: https://ecom-electromart.netlify.app/

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the app:
   ```bash
   node server.js
   ```
3. Open the site in your browser at `http://localhost:3000`.

## Files

- `index.html` – storefront landing page
- `shop.html` – product catalog
- `cart.html` – shopping cart
- `orders.html` – orders page
- `admin.html` – admin interface
- `server.js` – application backend
- `client.js` – client-side JavaScript

## Notes

- `node_modules` is excluded from version control using `.gitignore`.
